# Hair Day Salon Landing Page 

This project was completed as part of the **HTML and CSS in Depth** course within the **Meta Front-End Developer Professional Certificate** on Coursera.

It consists of a modern salon landing page built with **HTML5** and **CSS3**. The project showcases modern CSS layout techniques using **Flexbox** and **CSS Grid**, interactive hover animations, visual hierarchy, modern typography, and user-focused UI principles. It includes a promotional hero section, service cards, navigation components, and call-to-action elements, providing a clean and engaging user experience.

The course provided guidance and project requirements, while I independently implemented the landing page to reinforce the HTML and CSS concepts covered throughout the course.

### What I Learned

Building this landing page helped me strengthen my understanding of HTML5 and CSS3 by applying them in a practical project. I gained practical experience using semantic HTML, creating layouts with Flexbox and CSS Grid, styling interactive elements with CSS selectors, pseudo-classes, and transitions, and designing a user interface that balances visual appeal with intentional user engagement. The project also improved my ability to write clean, well-organised, and maintainable CSS.

### Continued Development

This project provided a solid foundation in HTML and CSS. In future projects, I want to continue improving my ability to create well-structured, accessible, and visually engaging web pages while writing cleaner, more scalable, and maintainable CSS. I also aim to further develop my understanding of modern layout techniques and user-centred design principles.
